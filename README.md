# 英语萌宠乐园 · Nancy's KET Park

> 给四年级孩子用的 KET（剑桥 A2 Key for Schools）备考 PWA。
> 每天 4 个 15 分钟环节，把 2209 个考纲词变成闯关游戏；家长一屏看完今天学得怎么样。

**打卡地址**：https://nancy808.github.io/ket-park/ （GitHub Pages，孩子日常打卡，可「添加到桌面」当 App 用，离线可用）

**投稿/体验地址**：https://nancy-ket-park.app.workbuddy.host/?sharecode=AO7VWCSG7E （WorkBuddy 应用，1024 造物挑战投稿作品）

> 两个地址是不同域名，学习数据各存各的、互不相通；认准孩子一直用的那个打卡即可。当前均为 **v1.15.6**。

## 这是什么

一个零后端、零安装的单文件网页应用（PWA）。孩子每天按顺序完成 4 个环节，集萌宠、得星星、通月份关卡；家长端有独立密码，看战绩、周报、调计划。

| 环节 | 内容 | 训练目标 |
|---|---|---|
| ① 背词 | 百词斩式四题型（看图/听音/中译英/填空）+ 连击战绩 + 错词本自动收集 | 词汇识记 |
| ② 跟读 | 整篇连读 + 评分五档 + 卡壳定位到「第几句哪个词」；录音自动保存，家长端周报可点听 | 朗读流利度 |
| ③ 听力 | 盲听答题 | 听力理解 |
| ④ 说+写 | 说一句、写一句、录音打卡 | 输出启蒙 |
| ⑤ 口语（额外） | 豆包 AI 对话打卡：内置提示词 + 计时 + 自评 | 真实口语对话 |

附加能力：KET 题型机（阅读 Part 1/2、写作 Part 6/7、听力 Part 1 选图 / Part 2 笔记填空 / Part 3 长对话、语法小练 50 题带解析）、🎓模拟小考（4 部分连做，计时 + 分项成绩单，进家长周报）、口语⑤每日五问 35 题库按日轮换（M1–M3 每天 10 分钟）、本周周报（可导出打印）、多孩子档案 PK 榜、单词量进度条、中断重启体系（中断任意天数后可从今天重开，月份进度跟随起点滚动）。

## 技术栈

- **前端**：单文件 `index.html`（约 2800 行）+ `data/*.js` 数据文件，无框架、无构建
- **PWA**：manifest + Service Worker（页面网络优先 / 音频缓存优先 / Range 直连网络）
- **存储**：localStorage（多孩子档案按 key 隔离），数据不出设备
- **音频**：334 个预录 MP3（单词 3 套音色 × 18 个月 + 读物 90 篇 × 3 套音色），播放按索引切片定位
- **音频管线**：Python 合成（单词用 edge-tts 微软神经网络英音 Sonia；短文用 Maisie）+ ffmpeg 拼切 + JSON 索引，工具在 `tools_*.py`
- **测试**：语法门禁（inline JS 校验）+ 题库结构单测 + 无头浏览器 dump-dom 冒烟（测到结算）+ 部署后线上 md5/版本复验

## 快速开始

```bash
# 本地直接打开（数据文件与 index.html 同目录，缺 data/ 会白屏）
open index.html

# 或起个静态服务
python -m http.server 8000
# 浏览器访问 http://localhost:8000
```

## 说明与边界

- 小猪佩奇配音为商业录音，受版权保护，朗读引擎不可用；默认音色为微软/gTTS 合法童声与女声音色。
- 跟读评分基于「完成度 + 卡壳定位」，不判断发音准确性（国内网络环境无法调用云端语音识别，产品内已如实说明）。
- 词库为 KET 考纲话题分类整理，非剑桥官方真题。
